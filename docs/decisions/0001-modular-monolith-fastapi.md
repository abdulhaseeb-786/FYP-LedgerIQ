# ADR 0001: Adoption of Modular Monolith with FastAPI and PostgreSQL

## Status
Accepted

## Decision
1. Architecture: Modular Monolith with Vertical Slices.
2. Framework: FastAPI.
3. Database: PostgreSQL with SQLAlchemy 2.0 (async) and Alembic.
4. Cache: Redis.
5. Deployment: Docker Compose with Nginx.
